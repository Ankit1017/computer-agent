## Swarm Overview

### Agents Configuration
- `agents.json`: Contains the configuration for our agents, specifying their roles, behaviors, and settings.

### Agent Code
- `agent_test.py`: An example of agent code used for testing and demonstrating the swarm's functionality.
- `binary_search_example.py`: Another example of agent code.

### Configuration and Logs
- `config.yml`: Essential for managing the swarm's configuration.
- `chroma.log`: Tracks the swarm's activities.
